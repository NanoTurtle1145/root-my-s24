   - `do_timer_create` 中 `kmem_cache_alloc(posix_timers_cache)` 返回点；

## 失败签名

1. 直接把 8 字节零写到 `selinux_state` 会清掉 `initialized`：
   - `getpeercon()` EINVAL、property set PERMISSION_DENIED、system_server 死亡、softdog panic；
   - 修复：写到 `selinux_state - 7`。
2. helper 直接从 `/data/local/tmp` exec 会被 KDP/DEFEX 杀；
   - 修复：UMH 跑 `/system/bin/sh` + action script，脚本里 bind-mount ksud 到 `/system/bin/logcat`。
3. `KERNEL_PHYS_LOAD` 错误会在 p0 阶段失败；DZJ3 验证 `0xa8000000`。
4. 同一 boot 只能跑一次 UMH 链；失败需真重启。
5. `WQ_DFL_PWQ_OFF` 6.1.145 是 `0xb0`，不能套 EZIF 的 `0x110`。
