> 免解锁免刷机 Root —— 只靠一个 App，纯软绕过三星 KNOX 防护，物理内存漏洞一键提权。

- **包名**: `cn.nanoturtle.rootmys9280`

## v2.5 更新亮点

### 1. 无线调试授权（替代 Shizuku）

不再依赖 Shizuku App：Android 11+ 手机开启「开发者选项 → 无线调试」，在 App 内输入系统显示的 IP:端口，用内置 ADB 协议客户端（纯 Kotlin 实现）直连授权。

- RSA 密钥对持久化（`files/adb/adb_key`），首次连接设备弹指纹确认框，点允许后授权完成，后续连接免弹窗
- 与 Shizuku 同为 shell (uid 2000) 权限，Root 流程完全等价
- 授权方式可在 Shizuku / 无线调试间自由切换（主页新增授权卡片）

### 2. 日志头部机型报告

每次运行开始时收集完整设备信息写入日志头部（设备型号 / 平台代号 / Android 版本 / 安全补丁 / 固件 build / bootloader / 完整指纹 / KNOX 状态），崩溃重启后日志依然可识别设备。

### 3. 日志导出按机型命名

导出文件名自动包含机型/固件标识（如 `rootmys9280-S9280ZCS6DZF2.txt`），多设备混测日志不覆盖、可归档。

### 4. 日志持久化恢复可见化

- 崩溃/重启后自动恢复日志，并插入可见提示（「已恢复 N 行」）
- 持久化写入失败不再静默，展示具体失败原因
- 导出兜底：内存日志为空时直接从持久化文件读取

### 5. 调试选项「自动保存日志」

设置页新增开关（默认开启）：关闭后日志不再实时落盘，仅内存显示。

## 使用方法

1. 安装 App，选择授权方式：
   - **Shizuku**：启动 Shizuku（无线调试或电脑 adb 授权），App 内授权
   - **无线调试**（推荐，无需装 Shizuku）：设置 → 开发者选项 → 无线调试 → 记下 IP:端口 → App 内输入连接
2. 选择你的**固件版本**（列表视图）
3. 点「开始 Root」——App 自动推送载荷 → LD_PRELOAD 触发 CVE-2026-43499 → 物理内存读写 → KASLR 绕过 → SELinux 降级 → root UMH → KernelSU late-load
4. 看到「Root 成功」即完成，重启后需重新执行（不可持久化）

## 技术栈（简要）

- **漏洞**: CVE-2026-43499（pipe physrw 物理内存读写）
- **链**: pipe 原语 → KASLR slide 检测（tracefs / boot_id 双路径）→ SELinux 降级 → `call_usermodehelper_exec` 提权 → KernelSU 加载
- **内核**: 6.1.99（BYH7）/ 6.1.145（DZE2–DZG1）
- **平台**: e1q（S9210）/ e3q（S9280）
- **授权**: Shizuku binder / 无线调试 ADB 协议（内置客户端）

---

## 注意事项

- 每次重启后需要重新执行 Root（系统更新也会清除）
- 无线调试端口每次开关会变化，重新连接时以系统当前显示为准
- 港版 DZG1（`S9280ZHS6DZG1`，构建 33419968）符号未知，若失败请提取该机型 boot 供定标
- 本工具仅供学习研究，请勿用于非法用途
