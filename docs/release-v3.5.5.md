# v3.5.5

## 本版重点：成功率修复

上一版（build 232/233）把 `EXPLOIT_ATTEMPTS` 误改成了 1，导致成功率从 70% 左右掉到 0–20%。
服务端数据看得很清楚：

| 版本 | 内部尝试数 | EZIF 成功率 |
|---|---|---|
| v3.5.2-beta.227（及更早） | 1/30 | 76–100% |
| v3.5.3 / v3.5.4（232/233） | 1/1 | 0–20% |

本版恢复 30 次内部尝试。43499 的命中本来就依赖 payload 内部重试，多数成功用例都落在
attempt 3–7，只给 1 次机会基本等于抽奖。
