## 本版主题：KernelSU 3.3.0 适配完成

S24 Ultra 国行（DZH3 线）正式加入 **KernelSU 3.3.0（versionCode 32601）** 支持，
并修复了导致管理器显示「未安装」的签名哈希问题。

真机验证（SM-S9280 / S9280ZCS6DZH3 / Android 16）：

```
LKM
工作中 [越狱模式]
版本：32601-2
管理器版本 v3.3.0 (32601-2)
SELinux 状态 强制执行        ← selinux_hide 生效
/proc/modules: kernelsu 221184 1 - Live
```

## 一、KernelSU 3.3.0（32601）适配

- **新增 3.3.0 驱动支持**：内核模块按 DZH3 内核（`6.1.145-android14-11-3254743-abS9280ZCS6DZH3`）
  编译，vermagic 逐字节对齐，导入符号 0 缺失、CRC 0 不匹配。
- **关键修复：模块的 Manager 签名哈希**　编译模块时误把 `KSU_EXPECTED_HASH` /
  `KSU_EXPECTED_SIZE` 覆盖成自签证书（`12daafaa…` / `0x318`），于是内核只认自签管理器；
  而实际安装的是官方 KernelSU 管理器（`c371061b…`），`Natives.is_manager` 恒为 `false`，
  管理器首页显示「未安装 + 越狱」。
  现已去掉覆盖、回到 Kbuild 默认值（本来就是官方管理器证书哈希 `c371061b19d8c7d7…` / `0x33b`）。
- **selinux_hide 生效**：管理器「SELinux 状态」显示**强制执行**。
  这是 3.3.0 独有的能力（3.2.5 做不到），也是本版适配的核心动机。
- 配套：管理器请使用**官方 v3.3.0**（versionCode 32601）。

## 二、KernelSU 驱动版本选择

- 机型页新增**「KernelSU 驱动版本」独立选项卡**（此前混在筛选芯片里、又在每张卡片重复显示，
  容易看晕），当前提供 `3.2.5` 与 `3.3.0` 两个选项。
- 版本清单**由服务端在线下发**，第一项即默认值（DZH3 线现已默认 3.3.0）。
- 版本按机型/固件生效（服务端 `devices` 字段），不适用的固件自动回退自身默认驱动并在
  选项卡下方提示。

## 三、机型页信息在线化

- **「已实测」标记改为在线获取**（新增 `PayloadStatus.kt`）：不再写死在 App 里，
  由服务端 `payloads.php` 下发；带缓存 schema 版本、6 小时 TTL、资产名白名单校验，
  远端可随时把某机型标为已实测。
- 「全部」筛选项下可看到所有可用驱动版本。

## 四、启动加速

- **Splash 从约 3.3 秒降到约 0.4 秒**。原因：原先串行等待 binder（最多 2500ms）后又固定
  `delay(800)`；现改为并行协程 + 窗口化等待（独立进程 400ms 窗口 / 寄生进程 1200ms 窗口）。

## 五、诊断能力（新增）

- **设置项「上传完整 raw 日志」**：`late-load` 输出不再被 `takeLast(300)` 截断 ——
  `loaded successfully` 与 `already loaded, skip` 这个关键分叉点此前正好被裁掉，导致
  日志里看不出到底加载了没有。
- **late-load 后自动抓内核 dmesg 判定段**，便于定位 `finit_module` 究竟被
  vermagic / 签名 / KDP 哪一道拦下。
- 管理器状态提示改为**动态**：报实际安装的管理器版本，不再写死 "v3.2.5 / 32525"。

## 六、服务端

- `payloads.json` + `payloads.php`：载荷、驱动版本、已实测状态的**远程控制面**，
  并汇总运行日志的成功率统计（仅计实际尝试过的运行）。
- `forum.php` + `forum_db.php`：讨论区与用户系统（含管理端用户管理）。
